개인정보처리방침

겜 만들어와는 세 개의 오프라인 게임을 제공하는 앱입니다. 앱 안에서 게임을 새로 생성하거나 계정을 만드는 기능은 없습니다.

앱이 저장하는 정보

게임 진행도, 최고 기록, 최근 플레이 정보와 모션 줄이기 같은 설정을 사용자의 기기 안에 로컬로 저장합니다. 이 정보는 게임을 이어서 플레이하고 선택한 설정을 유지하는 데 사용됩니다.

앱은 계정을 제공하지 않으며, 개발자 서버로 앱 사용 데이터를 수집하거나 전송하지 않습니다. 광고, 분석 도구, 로그인, 입력 폼도 사용하지 않습니다.

백업과 삭제

Android의 시스템 백업 설정이 허용되어 있어 운영체제 또는 사용자가 선택한 클라우드 백업 서비스가 앱 데이터의 백업·복원을 수행할 수 있습니다. 이는 개발자 서버 수집과는 별개이며 해당 운영체제와 백업 서비스의 설정 및 정책이 적용됩니다.

앱 설정의 “모든 게임 데이터 초기화”는 현재 기기에 있는 앱 소유 로컬 진행도와 설정만 삭제합니다. 운영체제나 클라우드에 이미 만들어진 백업은 앱에서 삭제할 수 없으며, 이후 복원될 수 있습니다. 백업 사본은 사용자가 기기 또는 백업 서비스 설정에서 관리해야 합니다.

로컬 데이터는 사용자가 앱에서 초기화하거나 앱 저장공간을 삭제할 때까지 기기에 남을 수 있습니다. 앱은 개발자 서버에 별도 보관본을 만들지 않습니다.

외부 서비스

앱은 사용자가 링크를 직접 눌렀을 때만 공식 사이트, GitHub Issues 또는 YouTube 채널을 외부 브라우저로 엽니다. 이동한 뒤에는 각 서비스의 개인정보처리방침과 이용 조건이 적용됩니다.

공식 사이트는 GitHub Pages에서 제공됩니다. GitHub는 사이트 운영과 보안을 위해 IP 주소 등 접속 정보를 기록할 수 있으며, 이는 앱의 로컬 게임 데이터 처리와 별개입니다. 자세한 내용은 GitHub의 개인정보 보호정책을 확인해 주세요.

문의는 공개 GitHub Issues를 이용합니다. 사용자가 자발적으로 작성한 문의 내용과 GitHub 계정 이름은 문제를 조사하고 답변하는 데 사용되며 공개될 수 있으므로 민감한 개인정보를 포함하지 마세요. 문의의 보관과 삭제에는 GitHub Issues 및 계정에서 제공하는 관리 기능과 GitHub 정책이 적용됩니다. YouTube 채널을 방문하면 YouTube/Google의 정책이 적용됩니다.

문의와 변경

개인정보 및 앱 관련 문의는 GitHub josh-yun의 겜 만들어와 공개 Issues에서 받습니다. 개인 이메일이나 우편 주소는 공개 문의처로 운영하지 않습니다.

앱 기능이나 데이터 처리 방식이 바뀌면 이 방침을 갱신하고 적용일을 표시합니다.
